外部平台登录助手

电脑端登录后传输到 Bili Sync

使用顺序
  1. 在 Bili Sync 设置页点击下面的“连接当前页面”
  2. 打开 YouTube、抖音或 TikTok，在本浏览器正常登录
  3. 点击对应平台的“传输 / 同步”按钮
  4. TikTok 请保持 tiktok.com 页面打开后点“同步 TikTok 会话”

同步 = 传输登录 Cookie。我的喜欢/关注列表仅需 cookies.txt 即可拉取（需干净出口 IP）。

等待操作

只传输 youtube.com、douyin.com 或 tiktok.com Cookie，不读取或传输账号密码。
